# Life Biosciences

> Life Biosciences is a Boston-based, clinical-stage biotechnology company developing therapeutics that target the biology of aging. Its epigenetic restoration platform — partial epigenetic reprogramming (PER) using the OCT4, SOX2 and KLF4 transcription factors — is designed to return older and damaged cells to a younger, healthier functional state. Lead program ER-100 is in a Phase 1 first-in-human study in optic neuropathies (open-angle glaucoma and NAION) after FDA clearance of the IND in January 2026; a preclinical program targets MASH.

Life Biosciences publishes no developer program, no API documentation and no SDKs. The only machine-readable surface reachable on its site is the read-only WordPress REST content API, which serves press releases, pages, media and taxonomies as JSON with no credential. This file was generated by API Evangelist from the company's public web surface and the site's own route discovery document — it is not published by Life Biosciences.
